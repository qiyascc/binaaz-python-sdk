# About

bina.az Python SDK is a typed client for bina.az, the Azerbaijani real estate site. It was written to let agencies and developers post and manage listings from their own systems instead of by hand on the website. It is not affiliated with bina.az.

## Author

The SDK is written and maintained by **Qiyas Sadıqov**. More of his work, including the other libraries listed below, is on [theqiyas.cc](https://theqiyas.cc).
